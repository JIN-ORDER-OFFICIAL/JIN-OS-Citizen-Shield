$$
J_{\text{score}} = \frac{(F_{\text{airness}} + C_{\text{ompassion}}) \times T_{\text{ransparency}}}{1 + (R_{\text{isk}} \times P_{\text{enalty}})}
$$

- **範囲**：0.00 ～ 2.00（理想値は1.5〜2.0）
